# Ember Trophy Guide

An offline guide and tracker for the 55 PlayStation 5 trophies of Grand
Theft Auto VI, built for the [make.fun gta6-trophy-guide-01
bounty](https://make.fun/c/gta6-trophy-guide-01).

Every trophy is shown with its official name, description and grade, plus a
guide in our own words that names its sources. The checklist saves progress
in the browser (with export and import), filters by kind and grade, hides
story spoilers until a trophy is earned, and tracks PSN's progress targets
with counters. A five-stage roadmap leads to the platinum, and a missables
watch list flags the trophies tied to a single event or mission — with an
honest verdict up top: no trophy is confirmed missable from its official
description alone.

## The list

55 trophies: 1 platinum, 2 gold, 6 silver, 46 bronze, 28 hidden — the
official PlayStation 5 list as Exophase and PSNProfiles list it, the two
agreeing on every name, description and grade.

## Play it

Serve `app/` with any static server and open `index.html` in desktop Chrome:

```sh
node serve.ts
```

No build step, no network requests, no external assets — the guide works
with the network off, and your progress never leaves the browser.
